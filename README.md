# Mirashya Stay — Airbnb-inspired listing UI

Desktop-only React and Tailwind implementation of a vacation-rental listing.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Included interactions

- Scroll-triggered compact section navigation
- Sticky booking card and expandable date panel
- Gallery open action and full-screen Photo Tour
- Single-photo lightbox with accessible close control, Escape, Left and Right keyboard navigation
- Section anchor navigation, show-more content, review/location/host sections

The app uses original React components and locally supplied image references. No Airbnb source code or remotely hot-linked Airbnb assets are used.

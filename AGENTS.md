# Agent workflow

## Visual fidelity
- Treat screenshots and observable reference behaviour as source of truth; never copy source code.
- Build reusable React components and preserve desktop keyboard access.
- Verify each state: initial listing, sticky navigation, booking card, tour and lightbox.

## Quality gates
- Run `npm run build` before submission.
- Check focus visibility and Escape/arrow-key overlay controls.
- Keep static assets local and avoid secrets or external service dependencies.
